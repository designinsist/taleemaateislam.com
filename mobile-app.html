Getting Started

How to Install

1
Download the appTap "Download for Android" above. The file is a standard .apk, ~22 MB.
2
Allow installationOpen the downloaded file. Android will ask permission to "install unknown apps" from your browser or files app the first time - tap Settings, then allow it, and continue.
3
Open and exploreLaunch Taleemaat-e-Islam from your home screen. Everything from the website is one tap away in the bottom navigation.

This is an early build shared directly from our website rather than the Play Store, so Android shows the standard "unknown source" prompt during install - this is expected and the app is safe. We are actively refining it before a full Play Store release.
